# SAGM-GWO: revised study and reproducibility package

This package accompanies manuscript STG-2026-08-0172, *Physics-Constrained Rolling-Horizon Self-Healing of Active Distribution Networks via Graph-Repaired Metaheuristic Search*.

## Contents and provenance

The simulation source matches the SHA-256 hashes recorded in `rerun_control/manifest.json` for the completed common-machine rerun. The manuscript, reviewer response, tables and figures use these rerun results. `audit/RESULTS_AUDIT.md` summarizes the verified results; `audit/verification.json` is generated by the independent archive checker.

| Location | Contents |
|---|---|
| `sim/`, `config/`, `data/`, root Python files | Executed simulator, frozen configurations and experiment drivers |
| `runs_r2/` | Main study (1,080 runs), plus separate IEEE 69-bus timing records |
| `supplement_runs/` | 120 additional runs: reserve 10/30% and critical priority 10/100, 30 seeds each |
| `development_runs/` | 10 calibration runs and 9 descriptive OSI/ERB audit runs |
| `phase_runs/`, `results_3ph/` | Paired BR/PA replay, 1,440 epoch records |
| `results_r2/` | Aggregates, paired tests, 24 MISOCP cases and 720 SAGM seed-level benchmark results |
| `figures/` | Figures 1–4 as PNG, PDF and editable SVG, with drawing scripts and Fig. 3/4 source tables |
| `documents/` | Updated manuscript and reviewer response |
| `rerun_control/`, `hardware.json` | Completed-run provenance and recorded environment |

Historical directory names containing `r2` are retained to preserve script paths. They are not controller names. `baseline_reference.json` supports before/after implementation diagnostics; its historical numbers are not the reported revised results. CAPA/TPFR are independent follow-up research and are not included.

## Main results

Values below are mean ± sample SD across 30 matched seeds; ENS is physical unserved energy over 24 hours.

| Manuscript label | Archived configuration label | ENS (kWh) | Successful runs |
|---|---|---:|---:|
| Snapshot-SAGM | Snapshot-Lean | 3361.4 ± 959.2 | 30/30 |
| RH, Tp=1 | RH-Lean Tp=1 | 2242.9 ± 307.7 | 30/30 |
| Full RH, Tp=5 | RH-Lean | 2120.8 ± 121.1 | 30/30 |
| Without branch-exchange refinement | RH-Lean w/o local search | 4071.5 ± 896.6 | 30/30 |
| Without graph repair and refinement | RH-Lean w/o graph repair | 6721.7 ± 1878.7 | 29/30 |

The last ablation disables both `repair` and `local_search`. The 3.17-fold ENS increase refers to their joint removal. Raw-candidate admissibility excludes branch-exchange fitness calls. One joint-ablation run (seed 17) sheds critical load; no fallback occurs in the 1,080-run pre-declared suite or either additional sensitivity sweep. The 20% reserve and priority-50 reference reuse the main nominal runs, so the two sweeps add 120, not 180, runs.

The Full RH versus Snapshot reduction is 36.9%. The Tp=5 versus Tp=1 paired ENS difference is not significant (Holm-adjusted p=0.678); final mean SoC is 41.3% versus 25.9%. The three-phase replay reduces under-voltage epochs from 298/720 to 67/720, with no converter-leg overload under the assumed 30-kVA rating.

Both 33-bus and 69-bus objective comparisons use AC-re-evaluated SCIP incumbents (`misocp_in_sim_J`). SCIP model values and solver MIP gaps remain separate fields. Table V reports full decision-epoch timing; Table VI reports search-only timing. A time-limited incumbent is not a proven optimum.

## Environment and execution

The archived rerun used AMD Ryzen 7 7840HS (8 cores, 16 logical processors), 32 GB installed RAM, Windows 11 and Python 3.12.7. Numerical-library threads were limited to one; the GPU was not used. `requirements.txt` records the pinned study dependencies. Numba warm-up is excluded from reported timing.

To check this delivered archive without running the experiments:

```powershell
py -3.12 .\audit_publication.py
```

To reproduce the study, first create a separate source-only directory, so the delivered results remain intact and completed checkpoints are not mistaken for a new execution:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\fresh_rerun.ps1
```

Enter the new `fresh_run_*` directory printed by the script. Run `CHECK_REPAIR.cmd`, then `RUN_ALL.cmd`. The runner creates a virtual environment, installs the pinned dependencies, records hardware, prevents idle sleep while running, and writes per-seed checkpoints. To continue an interrupted execution, run `RUN_ALL.cmd` again in that same new directory. `RUN_CONTROLLERS.cmd` omits the MISOCP benchmark and therefore does not reproduce the complete paper package. The SCIP limit is 1,800 seconds per fixed-epoch case.

The official descriptive development driver is `run_osi_erb_development.py`; there is no temporary sweep filename in this release. The terminal-reserve and critical-priority sweep drivers are `run_reserve_sweep.py` and `run_lambda_sweep.py`.

Figures 3–4 can be regenerated from the archived results with `python figures/draw_results.py`. See `figures/README.md` for architecture/workflow drawing scripts. Source/manuscript mapping and verification are provided without requiring a new long experiment run.
