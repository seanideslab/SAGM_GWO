# Figures

Figures 1 and 2 show the controller architecture and Algorithm 1 workflow. The reported edge score uses released P/Q and nominal voltage. Run `draw_fig1.py` / `draw_fig2.py` to regenerate PNG, PDF and editable SVG in their `outputs/` directory.

Run `python figures/draw_results.py` from the repository root to regenerate Figures 3 and 4 and their source CSV tables from the archived common-machine results. Figure 3 uses 30-run hourly means and cumulative-ENS standard-deviation bands. Figure 4 uses means ± sample SD; the ±10% bias markers are horizontally offset around x=10 for visibility.
